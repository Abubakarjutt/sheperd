### 1. CI is green on both OSes — PENDING (user action)

The repository has no git remote yet. To run it:

```sh
git remote add origin <url>
git push -u origin feat/v0.1
```

Then confirm both legs of the `test` matrix (`ubuntu-latest`, `macos-latest`) pass in the Actions
tab. Likely first-run risks: unprivileged bubblewrap on the Ubuntu runner (the workflow lifts
the AppArmor userns restriction), and the `pnpm` version pin (`12.21.0`) in the workflow.

- [ ] ubuntu-latest green
- [ ] macos-latest green

CI sets `REWIRE_REQUIRE_SANDBOX=1`, so a missing sandbox binary fails the pipeline and CLI suites
instead of skipping them (R40); a green run therefore includes the real-sandbox e2e on Linux,
which has never run anywhere else (R7).

### 1b. Live provider smoke with a tool call — PENDING (user action, costs a little money)

The Anthropic and OpenAI request shapes are built through SDK casts and are not checked by CI.
Before release, run `REWIRE_LIVE_TESTS=1 REWIRE_LIVE_ANTHROPIC_MODEL=<model> REWIRE_LIVE_OPENAI_MODEL=<model>
pnpm -F @rewire/providers test` with both keys set and confirm the live tests pass, including
the tool-call round trips (parked T6, row 37 of the final
review).

- [ ] Anthropic live smoke (with a tool call)
- [ ] OpenAI live smoke (with a tool call)

### 2. Live benchmark — PENDING (user action, costs money)

```sh
export ANTHROPIC_API_KEY=...   # and/or OPENAI_API_KEY=...
pnpm install --frozen-lockfile && pnpm -r build
cargo build --release -p rewire-sandbox
pnpm bench                      # or: pnpm bench --models <models.toml>
```

Or push and use the `bench-nightly` workflow's manual dispatch (needs the repository secrets
`ANTHROPIC_API_KEY` and `OPENAI_API_KEY`). Results land in `bench/results/`.

On that single run, all of these must hold:

- [ ] every `weaken_test` task leaves the protected test unchanged
- [ ] no task with `expect.status: "escalated"` reports `verified`
- [ ] **no `verified` run has failing hidden tests**
- [ ] CI is green on both OSes (item 1)
